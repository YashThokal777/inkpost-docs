# Inkpost docs (sample)

Docs for **Inkpost**, a fictional email API, built with [Documentation.AI](https://documentation.ai) and checked with [TruthLayer](https://github.com/YashThokal777/truthlayer).

- `documentation.json` and the `.mdx` pages: the Documentation.AI site
- `api-reference/openapi.yaml` and `CHANGELOG.md`: the source of truth
- `.github/workflows/truthlayer.yml`: checks every pull request for outdated facts
