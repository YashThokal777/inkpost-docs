---
title: API overview
description: Base URL, authentication and conventions for the Inkpost REST API.
---

The base URL for every request is `https://api.inkpost.example/v1`.

- Authenticate with a bearer token. See [Authentication](/getting-started/authentication).
- Requests and responses use JSON.
- List endpoints accept a `limit` parameter, up to 100 items per page.

The endpoint pages in this section are generated from the OpenAPI spec.
