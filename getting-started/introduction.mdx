Inkpost sends the emails your app needs: sign-up confirmations, password resets, receipts and alerts.

<Callout kind="info">
Inkpost is a sample product made to demo a docs workflow. The API, plans and prices on this site are fictional.
</Callout>

## What you can do

- Send an email with one API call
- Attach files to a message
- Get a webhook when a message is delivered, opened or bounced
- See every message in your logs
